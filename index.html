One core for email, identity and storage

kernoid is one self-hostable system for an organisation's core: an account is created once and can be at the same time the mailbox, the login for single sign-on and the owner of files. Free software in Rust – everything included.

0.2.0 – a pre-release, to try out and test

./get-started ./docs github.com/kernoid

what it is

Good free software exists for mail, for identity and for files – but as separate systems, each with its own users, its own administration and its own operations. kernoid is one system for all three.

one identity

Mailbox, login and file owner are the same object. Nothing to synchronise; leaving ends access everywhere in one step.

one administration

Users, groups, domains, roles and policies in one place – one interface, one API.

one operation

One container image on Docker or Kubernetes. It needs PostgreSQL and S3-compatible storage – nothing else.

everything included

Single sign-on, provisioning, multi-tenancy, clustering: one edition, free for everyone. No telemetry.

how it is built

open standards

SMTP, IMAP, JMAP, CalDAV, CardDAV, WebDAV; OpenID Connect, OAuth 2.0, SAML 2.0, SCIM 2.0 – LDAP with 0.2. The same protocols take your data out again.

on proven work

kernoid takes over AGPL code from Stalwart and carries the concepts of Zitadel over to Rust – credited in every file.

modules, not bloat

Connections to other services – video, office editing and more – are modules: off by default, switched on where they are needed.

apps under MIT

The server is AGPL-3.0; first-party apps are MIT and speak an open protocol. Anyone can write their own.

apps

The app for desktop and mobile – mail with end-to-end encryption, calendars, contacts and files – as a preview to try with a kernoid of the same version. It signs in through kernoid's login page in your browser. The builds are not signed yet: your system warns before it opens them. The web app and the terminal app come with the server.

macOS

macOS blocks an unsigned app from the browser. Either open the zip, move kernoid to Applications, open it once, then System Settings → Privacy & Security → Open Anyway – or fetch it in the Terminal, which is not blocked:

curl -fLO <download URL>
shasum -a 256 -c <file>.sha256
ditto -x -k <file> /Applications

Windows

Unpack the zip anywhere and start kernoid.exe. SmartScreen warns about an unknown publisher: More info → Run anyway.

Linux

Unpack and start kernoid in the folder. It needs GTK 3, libsecret and WebKitGTK 4.1 – on Debian and Ubuntu:

sudo apt install libgtk-3-0 libsecret-1-0 libwebkit2gtk-4.1-0

Android

Open the APK and allow installing from your browser. It is signed with a throwaway key: to update, remove the app first. For phones with a 64-bit ARM processor.

iOS

An iPhone installs only signed apps – iOS comes with the App Store, once falkOSS holds the developer account.

Check a download against its .sha256 file. Source, issues and the changelog: kernoid/apps (MIT).

roadmap

kernoid is in its pre-release phase: install it and tell us what you find – there has been no external security audit yet. The aim is a first stable release ready for production and running falkOSS's own email, logins and files – together with the app for desktop and mobile, once falkOSS is incorporated and holds the app stores' developer accounts.

  1. 0.1released 2026-10-28identity and single sign-on – OpenID Connect, SAML, SCIM, passkeys; mail – SMTP, IMAP, JMAP; calendars and contacts; files with WebDAV and team folders; the web app and a terminal app
  2. 0.2released 2026-10-30public links and drop boxes, uploads in pieces, LDAP, a Kubernetes operator with a Helm chart, end-to-end encryption with post-quantum keys, the core completed – the first modules: virus scanning and video calls (Jitsi) – and a preview of the app for desktop and mobile; the Rust SDK on crates.io
  3. 0.xuntil stableoffice editing (WOPI), external key management, DNS automation, help with moving in, hooks for other systems, an external security audit
  4. 1.0with falkOSS incorporatedstable – ready for production, with the app for desktop and mobile (macOS, iOS, Linux, Android, Windows)

Until then the web app and the terminal app are kernoid's own apps, and the app for desktop and mobile comes as an unsigned preview with each release; mail programs, calendars and file managers connect over the open protocols. Details in the changelog and the whitepaper.

name

Kern    German      → core
kerno   Esperanto   → core
kerno + id          → kernoid
kern0id, 0 as o     → kerno.id
kern0id, without 0  → kern.id
kernoid, OIDC       → OpenID Connect

Kern is German for core, and kerno is Esperanto for core. Both are in the wordmark kern0id: read the 0 as an o and it says kerno.id, leave it out and it says kern.id – the core, with identity; the dot in the 0 is the dot of the domain. kernoid joins the two: kerno and id. The oid also winks at OpenID Connect (OIDC), the protocol kernoid logs people in with, and, as an aside, at mathematics: the kernel of a map, and -oid as in monoid – kernel and monoid make kernoid.
